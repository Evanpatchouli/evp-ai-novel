# 测试范围

本目录验证工作台最重要的文件安全边界与单章终稿验收门槛。测试使用临时小说仓库，不得读写真实 `40_正文/`。

覆盖范围：

- 章节状态范围与统计；
- 仓库路径逃逸拒绝；
- 创建任务和导入工件不覆盖正文；
- 审稿报告原文无损保留；
- 五项人工终审确认门槛；
- 写入预览令牌、过期/重放/哈希冲突及事务性；
- Git 服务只读；
- Playwright 能力预留但默认关闭。
- React Router 页面直达与服务端 SPA 回退；
- 仓库会话切换、章号筛选和工作流阶段判断；
- 共享按钮不向原生 DOM 泄漏组件库私有属性。
- 任务包生成通知提供下载和打开文件夹操作。
- 任务包候选资料选择持久化、任务详情恢复及旧 ZIP 清单兼容。
- 工作台自有主题令牌不覆盖组件库保留令牌，避免通知背景声明失效。
- 页面顶部与人工决策面板复用同一待决策计数组件，并覆盖有值和零值显示。
- 组件库主题正确注入 `#9e3f2d` 主色，卷选择和人工决策不再回退为原生 `select`。
- 空状态显式使用工作台 `assets/empty.svg`，不回退到组件库默认图标。
- 已导入审稿报告在刷新后允许重新保存解析，记录人工决策后继续禁止覆盖。
- 工作流错误提示与下方内容保持独立间距。
- Dashboard 指标区和主卡片区使用组件库 `Grid`，不回退为自定义 CSS Grid。
- 前端入口使用工作台 PNG favicon，Dashboard 卷进度使用组件库 `Progress`。
- 审稿报告解析成功调用组件库静态成功 Toast，失败路径不误报成功。
- 全局页面快捷操作使用组件库 `GhostButtonGroup`，覆盖展开、刷新和回到顶部交互。
- Git 变化文件列表使用共享 `ScrollArea` 限制为 20 个标准行高，同时保留并可滚动访问全部记录。
